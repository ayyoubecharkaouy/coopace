# Noyau métier

État : module prévu, sans implémentation.

Ce module définira les modèles et règles communs : appareils, rôles, capacités, consentements, mesures, décisions bornées, évaluation et abstention.

Il restera indépendant des API réseau propres aux systèmes et du tableau de bord. Sa forme technique sera choisie en fonction des langages retenus pour les applications.
