# Tableau de bord

État : module prévu, sans implémentation.

Une interface web locale présentera les appareils, leurs rôles et capacités, les mesures et les interventions. Elle permettra de consulter les décisions et d'activer ou d'annuler les actions proposées selon les autorisations.

L'interface appellera des services applicatifs authentifiés ; elle ne manipulera pas directement les API réseau privilégiées. Son framework et son mode d'hébergement restent à choisir.
