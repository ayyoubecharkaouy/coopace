# Adaptation Windows

État : module prévu, sans implémentation.

Cette adaptation couvrira les besoins de l'agent Windows et l'étude du rôle passerelle. Elle devra annoncer précisément les mesures et actions disponibles sur le système installé.

WFP et les mécanismes QoS sont des pistes techniques, avec des limites à vérifier pour chaque fonction. Ils ne constituent pas à eux seuls un équivalent validé de CAKE/SQM. L'éventuel besoin d'un composant privilégié ou d'un pilote sera étudié avant implémentation.
